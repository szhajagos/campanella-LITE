# Developer documentation

This directory holds the developer documentation of Campanella Lite. It grows together with the code: a document is added when the part it describes is implemented.

## Documents

| Document | Describes |
| --- | --- |
| [installation.md](installation.md) | Requirements, web server, first-time setup, permissions, updating |
| [files.md](files.md) | File repository: uploads, ids, manifest, accepted types, `file` commands |
| [architecture.md](architecture.md) | Components, write path and read path, implementation status |
| [data-model.md](data-model.md) | Entities, file formats, identifiers, validation rules and violation codes |
| [command-language.md](command-language.md) | Syntax, batches, paths, responses, commands, developer CLI |
| [generator.md](generator.md) | Public addresses, redirects, page cache, rendering, themes, web server setup |
| [admin.md](admin.md) | Admin dashboard, first user, endpoints |
| [security.md](security.md) | How the public website, the admin and the files are protected |
| [development.md](development.md) | Setup, checks, CI, dependencies, releases, conventions |
