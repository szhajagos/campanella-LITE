A few commands to try in the admin area:

- `list pages` shows every page of the website.
- `content edit welcome`, followed by a text block, replaces this text.
- `page create --title="News"` adds a new page.
- `help` lists every command; `help page create` explains one.
- `undo` takes back the last change.

Every batch either runs completely or not at all, and `@dry-run` on the
first line shows what a batch would change without changing anything.
